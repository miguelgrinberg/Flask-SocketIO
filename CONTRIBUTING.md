# Contributing

First of all, thank you for your interest in contributing to this project!

Important:

- There is a [Code of Conduct](CODE_OF_CONDUCT.md) that must be followed in all your interactions with the maintainer, other contributors and users.
- Use of LLMs and other generative AI tools is not allowed.

## Issues

If you have found a bug in this project, please send the maintainer a description of the problem. If the bug is confirmed, the maintainer will create an issue for it.

## Pull requests

This project does not accept unsolicited pull requests.

If you are interested in contributing a change to this project, please introduce the change you wish to make to the maintainer.

Once the maintainer accepts your proposed change and allows you to work on it, you will receive instructions on how to submit a pull request.

## Contacting the maintainer

You can contact Miguel Grinberg (the maintainer) by [email](mailto:miguel.grinberg@gmail.com), social media, or by writing a draft issue on the GitHub mirror of this project.
